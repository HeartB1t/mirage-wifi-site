Install MirageWiFi

Download, unpack, launch: you are up and running in a few minutes.

Requirements

  • Kali Linux or another Debian-based distribution.
  • Root privileges (the auditing features need them).
  • At least one Wi-Fi adapter that supports monitor mode.
  • A web browser.
  • python3 with the python3-venv package.
  • An Internet connection on first launch (it downloads the dependencies).

Quickstart in four steps

  1. Download the package

    Get the Free edition package from the download page. Download MirageWiFi Free

  2. Unpack the tarball

    Extract the archive you downloaded into a folder of your choice.

  3. Launch MirageWiFi

    From the extracted folder, start it with root privileges.

    sudo ./start.sh

  4. Open the console in your browser

    Open the URL with the access token printed on startup.

    http://127.0.0.1:8731/#token=...

On first launch you accept the EULA and confirm you are authorized to test the target networks: the consent gate must be cleared before any auditing feature runs.

For a systemd service install, the .deb package and the system dependencies, see the README included in the package.
